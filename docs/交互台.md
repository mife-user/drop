# 可交互物体（交互台）接入指南

想做一个「**对准它 → 屏幕提示按 E → 弹出菜单 → 瞄准选 → 左键确认**」的物体（升级台、贩卖机、开关、NPC……），
**整套显示与流程都在基类里，你要写的只有「这一台卖什么」**。

现成的例子是水枪升级台：`scenes/水枪升级.tscn` + `scripts/水枪/水枪升级.gd`。

---

## 一、这套东西由什么组成

| 文件 | 类名 | 负责什么 | 接新物体时要动吗 |
|---|---|---|---|
| `scripts/交互框/交互台.gd` | `InteractStation` | **基类**：射线瞄准判定、E 开关菜单、面板转向、行高亮、左键确认、× 关闭、锁玩家移动与视角、准星提示、通用话术 | 不用动 |
| `scripts/交互框/交互面板.gd` | `InteractPanel` | 菜单面板本身：标题 / 若干行 / 底部信息 / 临时提示 / ×、命中判定、朝向 | 不用动 |
| `scripts/交互框/交互选项行.gd` | `InteractOptionRow` | 菜单里的一行：说明 + 价格 + 高亮 + 选中区，按真实字宽自动排版 | 不用动 |
| `scripts/交互框/交互准星.gd` | `InteractCrosshair` | HUD：屏幕中心的十字 + 它下面那行提示 | 不用动 |
| `scenes/交互台.tscn` | —— | **模板场景**：复制它起步 | **复制** |
| `scripts/水枪/水枪升级.gd` | `WaterGunStation` | 例子：只写「这一台卖什么」 | **照抄** |
| `scripts/人物/player.gd` | `Player` | 提供「锁走动」和「锁视角」，并把自己登记进「玩家」组供台座自动查找 | 不用动 |

## 二、接一台新物体：五步

### 1. 复制模板场景

在 Godot 文件系统里右键 `scenes/交互台.tscn` → **复制** → 改名，比如 `scenes/消防栓.tscn`。
（不要直接改模板本身。）

### 2. 换模型、量碰撞体

- 把 `模型`（那个灰色占位方块）删掉，换成你的模型。模型本身不用缩放到"刚好站住"，位置摆对就行。
- 调 `实体/CollisionShape3D` 的 `size` 和位置，**把模型包得稍微大一圈**。

这个碰撞体同时干两件事，所以层不能改：

| 层 | 值 | 作用 |
|---|---|---|
| 世界（第 1 层） | 1 | 挡住玩家，让玩家撞得到 |
| 可交互（第 5 层） | 16 | 让交互射线打得到 |

模板里 `实体` 已经设好 `collision_layer = 17`（1+5），菜单两行的「选中区」和 × 的「关闭区」是 16。
**这几个数字不要动**，基类的 `ray_mask` 默认就是 17。

### 3. 换脚本、写「这一台卖什么」

把根节点的脚本从 `交互台.gd` 换成你的新脚本。

> **`##` 和 `#` 不是一回事**：Godot 只认 **`##`** 开头的"文档注释" —— 只有它会显示在检查器里
> （鼠标停在属性上看到的那段中文说明）和 F1 帮助里；`#` 只是给人看的普通注释，检查器不认。
> **每个 `@export` 都要在上面写一行 `##`**，用中文说清楚「这个参数填什么、填了会怎样」。



```gdscript
extends InteractStation
class_name FireHydrantStation   # 不加 class_name 也行

## 消防栓：花邮币给水池扩容 / 让水枪射得更快。
## 显示、交互、锁人全部由基类负责，这里只写两行文字和"买完改什么"。

@export_group("接线")
## 邮币账本（右上角那个数字），花钱扣的就是它。留空的话这台机器不花钱。
@export var wallet: CurrencyLabel
## 要扩容的水池。拖场景里那个吸水区过来。
@export var sink: WaterSink
## 要改射速的水枪。拖主人公下的水枪发射器过来。
@export var gun: WaterGun

@export_group("水池扩容")
## 这一行左边显示的名字。
@export var capacity_name: String = "水池容量"
## 每升一级加多少立方米。
@export var capacity_step: float = 1.0
## 上限（立方米）；到了就不再涨价、也买不了。
@export var capacity_max: float = 8.0
## 第一级的价格（邮币）。
@export var capacity_cost: int = 5
## 每买一级，下一级贵多少。
@export var capacity_cost_step: int = 3

@export_group("水枪射速")
## 这一行左边显示的名字。
@export var interval_name: String = "水枪射速"
## 每升一级少多少秒。
@export var interval_step: float = 0.01
## 最短间隔（秒）；到了就不再涨价、也买不了。
@export var interval_min: float = 0.05
## 第一级的价格（邮币）。
@export var interval_cost: int = 4
## 每买一级，下一级贵多少。
@export var interval_cost_step: int = 2

@export_group("话术")
## 每行右边的价格怎么写，%d 是钱数。
@export var price_format: String = "%d 枚"
## 已经到顶时右边写什么。
@export var price_max_text: String = "已满级"
## 菜单底部那行怎么写，%d 是当前邮币。留空 = 不显示。
@export var footer_format: String = "邮币 x %d"

var _capacity_level: int = 0
var _interval_level: int = 0


func _ready() -> void:
	super()   # !!! 一定要调：基类在 _ready 里收菜单、把行铺好
	if is_instance_valid(wallet):
		wallet.money_changed.connect(_on_money_changed)


func _on_money_changed(_amount: int) -> void:
	refresh_rows()   # 钱一变，价格的颜色要跟着变


# ——— 基类要问你的六件事 ———

## 菜单有几行（模板里摆了 2 行，这里就返回 2）。
func row_count() -> int:
	return 2

## 第 index 行左边那句。
func row_text(index: int) -> String:
	if index == 0:
		return "%s  %.1f → %.1f m³" % [capacity_name, sink.capacity, minf(sink.capacity + capacity_step, capacity_max)]
	return "%s  %.2f → %.2f 秒" % [interval_name, gun.fire_interval, maxf(gun.fire_interval - interval_step, interval_min)]

## 第 index 行右边的价格。
func row_price_text(index: int) -> String:
	if _is_maxed(index):
		return price_max_text
	return price_format % _cost(index)

## 这一行现在能不能选（决定价格的颜色，也决定点了之后会不会被拦）。
func row_state(index: int) -> InteractOptionRow.State:
	if _is_maxed(index):
		return InteractOptionRow.State.DONE     # 到顶了 → 灰字
	if not wallet.can_afford(_cost(index)):
		return InteractOptionRow.State.BLOCK    # 买不起 → 红字
	return InteractOptionRow.State.OK

## 左键点了这一行之后干什么：扣钱、改数值、弹提示。
## 点完基类会自动重算一遍所有行，这里不用自己 refresh。
func on_row_activated(index: int) -> void:
	if not wallet.spend(_cost(index)):
		show_message(text_blocked, false)   # text_blocked 是基类的话术，默认「条件不满足」
		return
	if index == 0:
		sink.capacity = minf(sink.capacity + capacity_step, capacity_max)
		_capacity_level += 1
	else:
		gun.fire_interval = maxf(gun.fire_interval - interval_step, interval_min)
		_interval_level += 1
	show_message(text_success, true)

## 菜单底部那行（返回空字符串就不显示）。
func panel_footer() -> String:
	return footer_format % wallet.amount


# ——— 可选：菜单开关时要做的事（比如把自己的武器/音效关掉）———

func on_menu_opened() -> void:
	gun.can_fire = false   # 菜单里左键是「确认」，不关掉的话按左键会顺手滋出一发水

func on_menu_closed() -> void:
	gun.can_fire = true


# ——— 自己的小工具 ———

func _is_maxed(index: int) -> bool:
	if index == 0:
		return sink.capacity >= capacity_max - 0.001
	return gun.fire_interval <= interval_min + 0.0001

func _cost(index: int) -> int:
	if index == 0:
		return capacity_cost + capacity_cost_step * _capacity_level
	return interval_cost + interval_cost_step * _interval_level
```

### 4. 摆进主场景（**一根线都不用接**）

把新场景拖进 `main.tscn`、摆好位置，**完事**。

台座在 `_ready` 里把四个引用自动找齐（`InteractStation._resolve_refs()`）：

| 引用 | 自动怎么找 | 找不到会怎样 |
|---|---|---|
| 面板 | 自己下面第一个 `InteractPanel` 子节点 | 按 E 没反应（调试器里会有警告） |
| 碰撞体 | 自己下面第一个**挂在「可交互」层上**的碰撞体 | 准星打不到它，不弹提示 |
| 主人公 | 整个场景里「玩家」组里的那一个（`player.gd` 自己在 `_enter_tree` 里登记） | 菜单打开时锁不住玩家 |
| 准星 | 整个场景里「准星」组里的那一个（`交互准星.gd` 同样自己登记） | 屏幕上没有十字和提示 |

这四项**在检查器里没有格子、也不该有** —— 它们是接线，不是参数。少一格就少一个能配错的地方。

**结构跟模板不一样时**（碰撞体藏在子节点里、机器上零件特别多），
在子类里重写 `_resolve_refs()`：先填自己要指定的，再调 `super()` 让其余的照旧自动找。

```gdscript
func _resolve_refs() -> void:
	body = $外壳/碰撞体     # 这台机器的碰撞体藏得深，自己指定
	super()                # 其余三项照旧自动找（已经填了的不会被覆盖）
```

自己那台机器的业务引用（例子里是 `Wallet` / `Sink` / `Gun`）还是要接的 —— 那些只有你知道要接谁。

> 「玩家」和「准星」都住在主场景里，而你的台座是**单独存成一个场景**的 ——
> 在那个场景里它们根本不在，检查器里想连也连不上。
> 这就是让它们自动找的原因：台座场景保持自包含，拖进任何场景都能用。

### 5. 自测

进游戏走到跟前，应该看到：准星对着它 → 十字下面出现「按 E 交互」→ 按 E 弹出面板 →
转动视角把准星扫到某一行（那一行亮起来）→ 左键买下 → 右上角 × 关闭。

## 三、子类要覆盖的函数

基类里这 9 个是给你覆盖的，**前 5 个必须写**：

| 函数 | 什么时候调 | 返回 / 要做什么 |
|---|---|---|
| `row_count() -> int` | 每次刷新菜单 | 菜单有几行。取面板里实际摆的行数，多了的行会被自动隐藏 |
| `row_text(index) -> String` | 同上 | 第 index 行**左边**那句说明 |
| `row_price_text(index) -> String` | 同上 | 第 index 行**右边**那个价格 |
| `row_state(index) -> State` | 同上 | `OK` 正常 / `BLOCK` 选不了（价格标红）/ `DONE` 已完成（灰字） |
| `on_row_activated(index)` | 玩家左键点了这一行 | 扣钱、改数值、弹提示。**点完基类会自动刷新所有行**，不用自己调 |
| `panel_footer() -> String` | 每次刷新菜单 | 菜单底部那行（如「邮币 x 3」）；返回 `""` 就不显示 |
| `panel_title() -> String` | 每次刷新菜单 | 想让标题跟着状态变时才写；**返回 `""` 就用场景里「标题」Label3D 上写的字** |
| `on_menu_opened()` | 菜单刚打开 | 比如 `gun.can_fire = false`（见下面的坑） |
| `on_menu_closed()` | 菜单收起 | 还原现场 |
| `_resolve_refs()` | 开机时（`_ready`） | 自动找面板/碰撞体/主人公/准星。**结构跟模板不一样时才重写**：先填要指定的，再 `super()` |

基类还给子类留了几个能直接调的方法：`refresh_rows()`（重算所有行）、
`show_message(文字, 是否成功)`（在面板中间弹一句）、`open_menu()` / `close_menu()`。

## 四、菜单里那些「不用写代码」的东西

都在**面板节点**上摆，编辑器里所见即所得：

- **加一行**：在 `面板` 下再实例一个 `交互选项行.tscn`，摆好位置 →
  子类里 `row_count()` 改成 3、`row_text/row_price_text/row_state` 多处理一个 index。
  **行的顺序 = 场景树里的顺序**（用「上移 / 下移」调）。
- **一行的宽度**：跟着「高亮」那条 `QuadMesh` 的宽度走 —— 拉宽它，文字会自动重排。
  说明贴左、价格贴右，位置是按**字体真实量出来的字宽**算的，所以文案改多长都不会跑出框；
  实在长到放不下会自动缩字号（缩到 `Min Font Size` 为止）。
- **标题**：`标题` 这个 Label3D 的 `Text`，脚本不会覆盖它。
- **底部那行 / 临时提示**：内容是脚本给的，**颜色、字号、描边**改对应 Label3D。
- **× 的关闭区**：`关闭区` 这个 `Area3D` 的位置和大小，对准它的玩家才好点。
- **朝向**：面板默认每帧转向玩家（`Face Player` 勾着）。取消勾选就固定成你摆的朝向。
  注意脚本只接管**朝向**，位置还是你摆的。

## 五、钱怎么算

邮币账本是主场景 `界面/Money/Money2` 上的 `CurrencyLabel`（`scripts/money.gd`）：

```gdscript
wallet.amount            # 现在有多少（只读）
wallet.can_afford(price) # 买得起吗
wallet.spend(price)      # 扣钱；钱不够返回 false 且一分不扣
wallet.add_money(n)      # 加钱（以后打怪掉落、任务奖励调这个）
wallet.money_changed     # 信号：钱一变就发，接了它菜单能实时刷新
```

**测试用**：`scenes/money.tscn` 里的 `起始邮币`（`starting_money`）填多少开局就有多少。

## 六、玩家操作（现状）

| 操作 | 结果 |
|---|---|
| 准星对着物体 | 十字下面出现提示（文字在 `Prompt Text` 里改） |
| **E** | 打开菜单；菜单开着时再按一次 E = 关闭 |
| **左键** | 菜单里**确认**当前高亮的那一行；扫到右上角 × 就是关闭 |
| 走开 / 低头走远 | 超过 `Close Distance` 自动收起 |

菜单打开时会同时：

1. **锁住玩家走动和跳跃**（`Lock Player`，填 0 关掉这个行为）；
2. **把视角限制在朝面板 ±`Look Range` 度**（默认 35°，免得一转开就找不到菜单）；
3. **清掉准星下面的提示文字** —— 菜单里不加字，只靠「哪一行亮着」和 × 反馈。

菜单里**特意不用 Esc**：那个键在 `player.gd` 里是「放开鼠标」，按了会让光标跑出来打断操作。

## 七、坑（都踩过）

1. **射线默认打不到 `Area3D`**。菜单的行和 × 都是 `Area3D`，基类里已经设了
   `query.collide_with_areas = true`。你自己另外写射线时别忘了这一句，
   否则表现是「菜单能开、但一行都选不中」。
2. **隐藏 ≠ 不碰撞**。节点 `visible = false` 之后碰撞体照样在。所以菜单收起时
   必须把「选中区」和 × 的 `collision_layer` 归零（基类用 `set_deferred` 做了），
   否则一块看不见的判定框会横在玩家和物体中间，把「看着物体」变成「看着菜单」。
3. **子类写了 `_ready()` 就必须先调 `super()`**，否则基类不会收菜单、也不会把行铺好。
4. **菜单里左键是「确认」**，所以打开菜单时要把武器关掉（在 `on_menu_opened()` 里做），
   不然玩家点选项的时候会顺手开一枪。记得在 `on_menu_closed()` 里还原成**打开前的值**，
   别硬写 `true`（玩家可能自己在检查器里关过）。
5. **摄像机相对人物是转过 180° 的**（人物模型正面是 +Z，而摄像机朝自己的 -Z 看）。
   任何"算视角该转多少度"的代码都要减掉这个偏移，否则会整整差半圈 ——
   见 `scripts/人物/player.gd` 的 `lock_look()`，它直接读 `camera.rotation.y`，没有写死 180°。
6. **中文文字必须挂 `SystemFont`**。项目里没有任何字体文件，Godot 内置字体**不含中文字形**，
   不挂的话显示成方框。模板里已经挂好了，新建 Label3D 时记得照抄。
7. **一个子类的显示逻辑不要另写一套**。行怎么排版、面板怎么转、什么时候锁人，
   全在基类和 `交互选项行.gd` 里；要改就改公共件，所有物体一起受益。

## 九、已知的取舍

- **升级不存档**：退出或重开场景就回到初始值（项目里还没有存档系统）。
- **水块大小升级后，地上的旧水团不会跟新水团合并** —— 合并是按边长认的（容差 5%），
  边长变了就是另一档。这是水系统的既有设计，不是升级台改坏了。
